# Word-Frequency-Analyzer
一個實用的文字分析工具。透過定義獨立的 Python 函式，自動將文章轉為小寫並切分單字，接著運用字典 (Dictionary) 統計各單字出現的頻率，最終精準找出整篇文章中出現次數最多的「冠軍單字」。

核心功能:
-模組化設計：將核心邏輯包裝成獨立函式 find_top_word(text)，方便未來傳入不同文章重複使用。
-自動清理與統計：自動處理英文字母大小寫差異 (lower()) 並將文章切分為單字字串 (split())，準確寫入字典計算詞頻。
-冠軍篩選機制：透過 for 迴圈迭代字典，動態比對並追蹤出現次數最高的單字。

使用技術:語言：Python 3

核心語法：
-自訂函式 (def) 與回傳值 (return) 設計。
-字典 (Dictionary) 的資料建立與動態更新。
-字串處理方法 (.lower(), .split())。
-for 迴圈與 if/else 條件判斷。
